# Minesweeper.online scraper

**created for educational purposes only**

The program scrapes minesweeper.online for lost games from players. Game data is outputted via JSON in "losses" folder. 

Credit to use the program is not required but is appreciated. I am not responsible for misuse of this software.

Using the program requires downloading Playwright: https://playwright.dev/python/docs/intro
To use, log into your minesweeper.online account, or use a guest account via
``python login.py``
then, run the scraper via
``python scrape.py``

You are free to modify parameters within scrape.py as necessary.
